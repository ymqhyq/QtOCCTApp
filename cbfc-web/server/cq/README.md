# CadQuery parameter bridge

The abutment family is generated by `generators/generator.py` (CadQuery), not by
the Node mock geometry builder. To enable online parametric evaluation, install
CadQuery into a Python environment and point the server at it:

```powershell
python -m venv .venv-cq
.\.venv-cq\Scripts\python.exe -m pip install -r server/cq/requirements.txt
$env:CQ_PYTHON = (Resolve-Path .venv-cq\Scripts\python.exe)
pnpm dev
```

The Vite middleware calls `abutment_worker.py` for every `Abutment` evaluate
request:

```text
POST /api/v1/components/Abutment/evaluate
{ "modelNumber": "A4332-H5.0-D0.0",
  "parameterOverrides": { "FillHeight": 6.0, "EmbedDepth": 1.0 } }
```

The worker calls `generator.build_parts(params)`, tessellates each named part,
and returns a JSON mesh. `server/cq.ts` converts that payload into the same JHB
frame used by the rest of the viewer.

If `CQ_PYTHON` is absent or CadQuery cannot be imported, the API falls back to
the packaged `StraightAbutment.mesh.json` preview so the application remains
usable. In that fallback mode parameter fields can be viewed and presets can be
selected, but arbitrary parameter changes do not rebuild geometry.
