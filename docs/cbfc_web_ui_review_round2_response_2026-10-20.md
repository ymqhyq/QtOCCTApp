# UI 设计复审（第二轮）评估与整改记录

- 审核报告：[cbfc_web_ui_review_round2_2026-10-20.md](cbfc_web_ui_review_round2_2026-10-20.md)
- 整改日期：2026-10-20

## 1. 评估结论

Gemini 第二轮报告中的主要问题成立。表格视图、版本号统一、任务中心等已通过项保持有效；本轮重点处理了主路径、监控图误导、默认可见性、内部术语和视口遮挡。

## 2. 已整改

### P0

| 编号 | 问题 | 处理 |
| :--- | :--- | :--- |
| P0-1 | 详情页缺少型号选择 | 详情页右栏新增「标准型号」选择器，切换后重新求值/加载对应 JHB，并联动外包尺寸、净体积、强度等级；下载请求携带当前型号 |
| P0-3 | 时延图按耗时画条长 | 条形长度改为按调用次数；P95 作为标签显示 |
| P0-4 | 配置器“保存并下载”误导 | 改为「下载基准型号」，并提示自定义变参暂不打包；导出请求带当前标准型号 |
| P0-5 | 设计师默认看到草稿 | 非资产管理员默认状态筛选为「已发布」；管理员保持全部 |

### P1 / 信息架构

- 单型号族在目录树中合并为单行叶子节点；
- 「映射健康度」仅资产管理员/标准管理员可见；
- 构件卡片、表格标题去除“（CQ 脚本）”“（构件库2）”来源后缀；
- 导航栏支持拖拽宽度（184~300px，默认 208px，持久化）；
- 资产目录与导航栏贴合，并在顶端/底端对齐。

### P1 / 文案清理

- 工作台页脚移除 `Round 6`；
- 监控看板副标题改为业务描述；
- 语义中枢移除 `Server-side Resolver`、`前端零规则副本`、原始 `POST /api/v1/...` 调试行；
- 导出格式卡移除 `P0/P1` 徽标，JHB 描述改为应用层说明；
- 审核台隐藏 `ZERO-COPY / cacheKey / payload` HUD；
- 详情页 `true/false` 改为「是/否」，`V/T` 改为「顶点/面片」，移除 `faceToShape` 等内部符号；
- 构件描述移除算键/测试向量文案。

### P2 / 视口与门禁

- 详情页/审核台左上角标签下移到工具栏下方，避免遮挡；
- 审核台增加「基准旧版 / 送审新版 / 重叠对比」显式切换；
- 线宽控件增加动态 Tooltip；
- 入库门禁失败时在门禁区顶部显示阻断总览，附下载报告/重新检测；
- 配置器派生计算移除重复的 NetVolume 行。

## 3. 未完全闭环

- 配置器自定义变参结果的 `.cbfc` 打包仍未实现，当前只支持标准型号基准包；
- 审核通过后的几何网格重建未完成；
- 全局空值符号尚未全部统一为 `–`；
- 三处搜索框仍并存，保留为不同层级入口；
- 侧栏在资产大厅默认折叠未强制实施。
