# 角色化信息架构与页面收敛

## 导航

| 角色 | 导航 |
| :--- | :--- |
| 设计工程师 | 工作台、资产大厅、构件入库、导出中心、个人收藏、历史 |
| 标准审查专家 | 工作台、资产大厅、审核质检 |
| 资产管理员 | 工作台、资产大厅、族库管理、构件入库、审核质检、语义标准中枢、监控看板、导出中心 |
| 标准管理员 | 工作台、资产大厅、语义标准中枢、监控看板、导出中心 |
| 外部合作方 | 工作台、资产大厅、个人收藏 |

导航项由 `src/navigation.ts` 统一维护，顶栏、侧栏、命令面板共用。

## 页面边界

- **审核质检 `/reviews`**：只做专家审查和通过/驳回；不承担提交人自审核。
- **构件入库 `/ingestion`**：上传、门禁、提交发布审核；3D 验真和技术明细默认收起。
- **资产大厅 `/library`**：分类目录、名称编码检索、专业/状态/几何能力过滤；不提供尺寸区间过滤。
- **构件详情**：普通设计工程师只看几何、语义、投影、版本；缓存/QA/门禁明细仅管理员和审核员可见。
- **语义标准中枢**：管理员从导航进入编辑；普通内部用户可从工作台「标准映射 → 查看」进入只读沙盒，并自动定位到 unmapped 筛选。
- **导出中心**：格式、许可、下载；Handoff/深链规范不再作为默认页面。
- **监控看板**：KPI/趋势/失败任务常驻；存储、CAS、审计日志收进高级信息。
